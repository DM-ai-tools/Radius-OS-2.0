Publishing is not the end state
Business & Project Discovery (Phase 1) and Access, Tracking & Data Collection (Phase 2) have both moved from Gap to Resolved, closed by TR's own Phase 0 and Phase 0.5 workflows rather than a SearchFit skill — so SearchFit's own 15-skill catalog still shows zero coverage for either. The remaining 3 true gaps are all downstream or off-site, not upstream: Local SEO (13), Authority/Links/Digital PR (14), and Conversion & UX Optimization (15) — nothing built so far touches any of them.

Two distinct kinds of work now sit in this table. The three Gap phases need new skills built from scratch, then roles assigned. The phases marked "v1.9 gap to close" (2, 3, 4, 10, 17) have working skills that need enhancement — theme clustering, competitor override and service-level depth, penalty detection, funnel-stage tagging, and the post-publish loop. The second set is cheaper and unblocks the pipeline sooner; the first set is what expands its scope.
