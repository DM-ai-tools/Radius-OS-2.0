# Topic strategy from the Comprehensive Headline Framework

Source: *Comprehensive Headline Framework for All Content Assets* — Strategic Guide to Creating High-Converting Headlines Across Marketing Channels.

## Core equation

**Interest = Curiosity + A BIG PROMISE (strongly desired benefit)**

Every topic title must:
1. Open a curiosity gap (what they know vs what they want to know)
2. Promise a concrete benefit ("what's in it for me?")

Honesty guardrail: never invent statistics, authority names, social-proof counts, guarantees, or outcomes. Specificity comes only from keyword metrics, audience/pain from CDD, outline counts, and geography.

## Topic strategy pipeline (Phase 5 Create Topic)

1. **Primary keyword** — exact phrase from Multi-mode keyword seeding (one per service when possible).
2. **Search intent** — informational / commercial / transactional (from keyword).
3. **Keyword type** — `match_class`: exact | phrase | related | broad.
4. **Traffic temperature** (framework Part 5):
   - informational → **cold** → TOFU (problem identification, mistakes, how-to-without)
   - commercial → **warm** → MOFU (comparison, superiority, objection removal)
   - transactional → **hot** → BOFU (action, exclusivity, next steps — no fake guarantees)
5. **Content format** from intent + type:
   - exact + informational → guide / what-is (pillar)
   - phrase + informational → how-to
   - related + informational → mistakes / warning-signs
   - commercial → listicle / comparison
   - transactional → templates / advanced / practical path
6. **Title** — blog templates (framework Part 3-D / Part 8) via `headline_framework`, with audience + pain point when known.
7. **Secondary keywords** — same seed/service family only.
8. **Unique angle** — name the template + traffic + service so the plan stays differentiated across topics.

## Blog required inputs (framework Part 7)

| Input | Source in Radius OP |
| --- | --- |
| Target keyword | Multi-mode seeded primary |
| Target audience | CDD demographic (flattened label) |
| Core topic | Seed / service / parent topic |
| Benefit / value | Derived from keyword + pain (no invented outcomes) |
| Content format | Intent + match_class mapping above |
| Specificity element | Volume/KD, year, outline count — never fake stats |
| Search intent | Keyword intent |
| Unique angle | Template + competitor gap when present |
| Supporting keywords | Same-service secondaries |
| CTA | Deferred to Phase 10 content production |

## Cold / warm / hot formulas we use (honest subset)

**Cold (TOFU):** Struggling With [Problem]?; [N] Mistakes; How To [Benefit] Without [Objection]; What [Audience] Needs To Know.

**Warm (MOFU):** [Topic] vs alternatives; Best [Topic] Strategies; [Benefit] Even If [Objection]; Why [Audience] Should Care.

**Hot (BOFU):** Practical path / next steps; Templates & Frameworks; Advanced [Topic] — never invent "guaranteed" or "spots left" without client-supplied facts.

## Differentiation

Vary templates across the topic plan. No two adjacent topics should share the same `angle_category`. Prefer shapes that are not already dominating competitor SERP titles when SERP context is available.
