# 4Ps — Promise, Picture, Proof, Push

Use for products and offer-led pages.

1. **Promise** — the single most valuable outcome, stated up front.
2. **Picture** — what using it is actually like, concretely.
3. **Proof** — specifications, evidence, credentials, named results. Only what
   the brief supplies.
4. **Push** — one clear next step with any genuine, dated urgency. Never invent
   scarcity or a deadline.
