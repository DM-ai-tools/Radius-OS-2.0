# Skill: FAQ page

**Structure** — H1 naming the topic; questions as H2s grouped by theme; each
answered in 40-80 words before any elaboration.

**Rules**
- Only real questions. Never a keyword variant dressed as a question.
- Answer the question in the first sentence, then add context.
- If an answer depends on circumstances, say which.
- No answer may invent policy — refunds, timelines, warranties, eligibility.
- Schema: FAQPage, with every Q&A on the page represented.

**CTA** — soft, with a route to a human for anything not covered.
