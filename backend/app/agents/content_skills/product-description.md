# Skill: Product description

**Structure** — H1 as the product name; the one-line reason to buy; key benefits
tied to features; specifications; what's in the box / what's included; FAQ.

**Rules**
- Every benefit traces to a stated feature. No unsupported superlatives.
- Specifications come only from the brief. Never estimate a dimension, weight,
  material, compatibility or price.
- Address the top purchase objection explicitly.
- Schema: Product with Offer. Include price and availability only when supplied.

**CTA** — transactional: add to cart, buy now, check availability.
