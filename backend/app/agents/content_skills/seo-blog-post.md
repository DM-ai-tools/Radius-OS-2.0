# Skill: SEO blog post

An informational article that earns the click and answers the query completely.

**Structure** — H1 matching search intent (not necessarily the exact keyword);
answer in the first 100 words; H2s that are real subtopics, not keyword variants;
a short FAQ where genuine related questions exist.

**Rules**
- Answer first, context second. No "in today's world" openings.
- One idea per H2. If two H2s answer the same question, merge them.
- Internal links: 2-5, to pages named in the brief only. Never invent a URL.
- No word-count target. Length follows coverage.
- Schema: Article. Add FAQPage only when a real FAQ block exists.

**CTA** — soft. Related reading, a checklist, or a newsletter. Never "book now".
