# Skill: Comparison post

**Structure** — H1 naming both options; the verdict in the first 100 words;
criteria used; a comparison table; when to pick each; who each is wrong for; FAQ.

**Rules**
- Give a verdict. "It depends" is only acceptable with the dependency named.
- Criteria must be stated before the comparison, and applied to both sides.
- Be fair to the option you do not recommend. Name a real strength.
- Never invent pricing, features or benchmark numbers for either option.
- Where one option is the client's, disclose that plainly.
- Schema: Article. Add FAQPage where a real FAQ exists.

**CTA** — medium: a trial, a demo, or a consultation to decide.
