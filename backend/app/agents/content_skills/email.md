# Skill: Email

**Structure** — subject line (under 50 characters); preview text that adds rather
than repeats; one-idea body; one CTA.

**Rules**
- One email, one job. If there are two asks, it is two emails.
- The subject line must not overstate the body. No false urgency or fake
  personalisation.
- Short paragraphs, second person.
- Only reference an offer the offers signal supplied as active, with its real
  end date if stated.
- No schema; this is not a web page.

**CTA** — one, matched to funnel stage.
